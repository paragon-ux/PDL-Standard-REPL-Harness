# Artifact Standard

Normative scope: structural replacement and model-output boundary shared by Prompt and Response Plan artifacts.

**ARTIFACT-01 — Complete replacement.** An authorized Prompt or Plan revision MUST produce a complete replacement artifact rather than a patch.

**ARTIFACT-02 — Artifact-body boundary.** Prompt or Plan generation/revision model output MUST contain only the requested artifact content and MUST NOT add lifecycle framing owned by the host presentation layer.
