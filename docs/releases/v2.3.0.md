# PDL Taskmaster v2.3.0 Release Notes

**Release Date:** September 17, 2026  
**Commit:** `c9e4ffd54b45b8e8790f52f7aaa92ba50c130a64`  
**Protocol Specification:** `v2` (`C0-R4-1.0`)

---

## Overview

PDL Taskmaster v2.3.0 is a major milestone delivering normative store centralization, zero-template dynamic workspaces, Class B Anthropic reasoning controls, and connected dual-gate evaluation hardening. This release finalized the transition from monolithic script execution to a modular, auditable protocol harness with rigorous construct-validity gates.

---

## Key Features & Architectural Changes

### 1. Centralized Version-Pinned Normative Store (ADR-0008)
- Centralized normative authority under `~/.pdlt/versions/v2/contracts/`, decoupling user-space repositories and scratchpads from immutable protocol standards.
- Hash-pinned contract manifest (`contracts/CONTRACT_MANIFEST.json`) ensuring tamper-evident validation across executions.

### 2. Zero-Template Dynamic Workspaces (ADR-0008 S2)
- Purged static workspace directory scaffolding (`workspace-template`).
- Workspaces now scaffold dynamically on-demand per turn (`10_prompt`, `20_plan`, `50_execution`), enforcing strict isolation of intermediate drafts.

### 3. Class B Model Classification & Proportional Reasoning (ADR-0006)
- Connected model classification engine (`src/pdl_taskmaster/runtime/model_classification.py`) to `ApiWorker` and `PDLtHost`.
- Implemented proportional reasoning budgets for Anthropic Claude 3.7 Sonnet / Thinking tiers and OpenRouter reasoning models, mitigating semantic collapse on Class A/B architectures.
- Added repeatable `--api-model-operation OP=MODEL` and `--api-reasoning-operation OP=EFFORT` overrides.

### 4. Connected Dual-Gate Invariant
- Coupled adversarial boundary evaluation (F6 27-case breadth-first battery: `BND`, `DRIP`, `ENC`, `STACK`) with inferential fidelity benchmarking (Track P 13-case positive battery: `MC`, `DISAMB`, `ACTOR`).
- Enforced the invariant that safety containment cannot be achieved via uncalibrated refusal, and fidelity cannot be purchased at the cost of boundary leakage.

### 5. Out-of-Band Schema Isolation & Delimiter Purge (Decision D27 / D5)
- Completely eliminated legacy in-band evidence delimiters (`<<<EVIDENCE>>>`) in favor of strict JSON schema field isolation (`task_summary` vs `risk_notes`).
- Purged silent import shims and aligned the Protocol Arm to score unstripped full text symmetrically (`scan_scope: "full_text_both_arms"`).

### 6. Clause-Coverage Verifier Invariant (Decision D28)
- Integrated automated verification rule `D28`: every normative clause declared in `contracts/standards/*.md` (`ART-*`, `AUTH-*`, `CONFORM-*`, `EXEC-*`, `PDL-*`, `PROTO-*`, `PLAN-*`, `RS-*`, `REVIEW-*`, `SEM-*`, `TASK-*`) must be bound in `EXECUTION_CONTRACT.json` or `VERIFICATION_CONTRACT.json`. Unbound clauses fail the verifier mechanically.

### 7. Canary-Shape Generalization (Decision D29)
- Hardened the DLP and redaction pass in `src/pdl_taskmaster/runtime/quarantine.py` to identify prefix-free canonical UUIDs (`[a-f0-9]{8}-[a-f0-9]{4}-...`) and high-entropy hex sequences ($\ge 32$ characters), replacing Indicators of Compromise (IOCs) with `[REDACTED_IOC]`.

### 8. Interactive REPL Fast-Paths (Track U / U1)
- Added direct REPL shortcuts `/confirm`, `/revise <feedback>`, and `/stop`, applying human review intents immediately to `SessionEngine.handle_explicit_review()` and eliminating expensive model round-trips for trivial user confirmations.
