# PDL Taskmaster v2.4.0 Release Notes

**Release Date:** September 26, 2026  
**Commit:** `1646860be70a56553fedf39caf462932be919766`  
**Distribution:** PyPI [`pdl-taskmaster`](https://pypi.org/project/pdl-taskmaster/)  
**Protocol Specification:** `v2` (`C0-R4-1.0`)

---

## Overview

PDL Taskmaster v2.4.0 transforms the repository from a local developer workspace into an official, pip-installable Python package and CLI distribution (`pdl-taskmaster`). It introduces Pydantic v2 structured wire enforcement across all protocol boundaries, an in-memory Virtual Filesystem substrate delivering sub-millisecond stage transitions, a 4-tier standards precedence ladder with bundled package data, a unified umbrella CLI (`pdlt`), self-contained offline test suites, and support for non-generative System 1 decision architectures (Laya / Jev Router).

---

## Key Features & Architectural Changes

### 1. Standard Python Package Distribution (`src/pdl_taskmaster/`)
- Relocated runtime and harness code from `scripts/` to a clean `src/pdl_taskmaster/` package root while preserving full `git blame` / provenance history.
- Packaged using modern PEP 517/518 and PEP 621 standards with `hatchling` and `uv`.
- Configured PyPI Trusted Publishing via OpenID Connect (OIDC) under `.github/workflows/publish.yml`.
- Standard installation:
  ```bash
  pip install pdl-taskmaster
  # or with uv:
  uv add pdl-taskmaster
  ```

### 2. Umbrella Command Line Interface (`pdlt`)
- Built an umbrella console entry point unifying all harness operations:
  ```bash
  pdlt                         # Launch default interactive REPL
  pdlt version                 # Inspect package, protocol, and manifest versions
  pdlt init --global           # Seed standards into ~/.pdlt/versions/v2/contracts/
  pdlt init --local            # Seed standards into ./contracts/
  pdlt verify                  # Run deterministic baseline verifier
  ```

### 3. 4-Tier Normative Store Precedence (`NormativeStore`)
- Dynamic contract resolution ladder:
  1. `PDLT_STANDARDS_PATH` environment variable.
  2. Local `./contracts/` in current workspace.
  3. User cache directory `~/.pdlt/versions/v2/contracts/`.
  4. Bundled package data via `importlib.resources.files("pdl_taskmaster").joinpath("contracts")`.
- Enables running the full protocol lifecycle anywhere without manual directory configuration.

### 4. Pydantic v2 Schema Enforcement (ADR-0010)
- Strongly typed Pydantic v2 `BaseModel`s for all semantic operations:
  - `ActivationDecisionPayload`: Discriminated route typing with confidence thresholds.
  - `BootstrapAnalysisPayload`: Out-of-band threat telemetry and verbatim entity extraction.
  - `PromptDraftPayload`: Validated prompt IR bodies and approach handoffs.
  - `ReviewFactsPayload`: Normative dimension validation and progression gating.
  - `ExecutionDraftPayload` & `ExecutionOutcomePayload`: Delivery markers, execution entities, and Result IR validation.
- Direct JSON Schema emission via `model_json_schema()` to drive `--api-structured-output`.
- Precision, automated operator corrections generated from `ValidationError.errors()` for zero-delay recovery on model glitches.

### 5. In-Memory VFS & Ephemeral Sandboxing (ADR-0011)
- `MemoryWorkspaceRun` and `MemoryAtomicJsonStore` in-memory substrate executing stage handoffs entirely in RAM buffers.
- Eliminates Windows NTFS `os.fsync()` overhead, slashing workspace turn I/O latency from **~3,000ms to $<1\text{ms}$**.

### 6. System 1 Decision Architecture & Jev Router Integration (ADR-0012)
- Replaced slow autoregressive review interpretation with non-generative classification heads operating in a single forward pass.
- Verified compatibility with `typesafe/jev-router` via OpenRouter:
  - **Latency:** ~1.6s classification (down from 15s+ on heavyweight LLMs).
  - **Fail-Closed Confidence Gating:** Calibrated posterior confidence threshold ($\theta_{floor}=0.85$, margin $\Delta \ge 0.40$); unconfident or ambiguous reviews rewrite to `UNRESOLVED` (enforcing `REVIEW-09`), while ambiguous activation defaults to `APPLY_PROTOCOL`.
  - **Adversarial Containment:** Validated containment of jailbreak and prompt injection probes into safe `PROTOCOL_DISCUSSION` states.

### 7. Self-Contained Offline Test Suite & Vendored Fixtures
- Vendored minimal, representative test fixtures under `tests/fixtures/` (~220KB), enabling 100% offline pytest execution (87 passed, 1 skipped) without requiring external archives.
- Clean distribution split: wheels (`.whl`) contain zero test/run bloat; source distributions (`.tar.gz`) package the complete test suite for downstream packagers.
