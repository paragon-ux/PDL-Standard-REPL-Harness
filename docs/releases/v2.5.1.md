# PDL Taskmaster v2.5.1 (Alpha) Release Notes

**Release Date:** September 28, 2026  
**Distribution:** PyPI [`pdl-taskmaster`](https://pypi.org/project/pdl-taskmaster/)  
**Protocol Specification:** `v2` (`C0-R4-1.0`)  
**Architecture Decisions:** [ADR-0017](../adr/0017-dual-plane-runtime-realignment-and-mrv-solver-governance.md)  

---

## Overview

PDL Taskmaster v2.5.1 (Alpha) bridges the gap between frontier deliberate reasoning and low-latency semantic gating by deploying the Dual-Plane Runtime architecture. It wires System 1 (`typesafe/jev-1.13-20260917` / ModernBERT) into the REPL host pipeline, introduces a live session inspection web UI (`/viewer`), and provides non-interactive prompt file ingestion for automated evaluation.

---

## Key Features & Enhancements

### 1. Dual-Plane Runtime Realignment: System 1 Baseline (ADR-0017)
- Integrated `Sys1Client` and `ModernBertWorker` into the default REPL activation pipeline.
- Added recipe-driven classification:
  - `ProblemClassRecipe`: Deterministically classifies whether user prompts require mechanical verification (`VERIFIED_EXECUTION`) or general structured completion (`STANDARD_EXECUTION`).
  - `ActivationRouteRecipe`: Evaluates leading skills and invocation intent prior to System 2 activation.
- Runs in **~140ms with $0.000019 per call**, filtering out trivial tasks and pre-configuring verification requirements without consuming frontier model reasoning tokens.

### 2. Live Session Viewer Web Dashboard (`/viewer`)
- Introduced `pdl_taskmaster.tools.viewer_server`: an embedded, zero-dependency HTTP server and browser UI.
- Interactive inspection of active sessions:
  - Workspace directory tree and stage outputs.
  - Step-by-step telemetry, API round-trip timings, and token metrics.
  - Deliverable cards and live syntax-highlighted code blocks.
- Accessible directly from the REPL via `/viewer` command or via standalone CLI `pdlt viewer`.

### 3. Subprocess Multi-Line Ingestion (`--prompt-file`)
- Added `--prompt-file <path>` to `pdl_taskmaster.host.repl` and the umbrella CLI `pdlt`.
- Eliminates shell pipe and stdin escaping anomalies on Windows PowerShell when ingesting large, multi-paragraph prompts containing nested triple quotes, docstrings, or code blocks.

### 4. REPL ASCII-Safe Deliverable Cards
- Shipped `format_friendly_deliverable` for standard REPL view mode.
- Replaces raw, verbose Result IR JSON blocks with clean, ASCII-safe markdown deliverable summaries (`[+] satisfied`, `[-] defect`, `* files modified`), avoiding `cp1252` terminal crashes on legacy Windows consoles.

### 5. Automated Catalogue Evaluation Runner
- Established `catalogue-runs/run_catalogue.py` in `PDLt-Test`.
- Supports automated headless evaluation across individual categories, single-prompt targeting (`--prompt-id`), and MLflow tracking synchronization.
