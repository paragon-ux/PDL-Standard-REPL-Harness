# Stable workspace references

Layer 3 configuration for Condition C.

- Normative source: `contracts/standards/` in the installed runtime.
- Applicability source: `contracts/EXECUTION_CONTRACT.json`.
- Verification mapping: `contracts/VERIFICATION_CONTRACT.json`.
- Stage `references/operation-bindings.json` files contain requirement IDs and structural
  routing metadata only; the runtime resolves clause text and output schemas from the
  authoritative contract surfaces.
