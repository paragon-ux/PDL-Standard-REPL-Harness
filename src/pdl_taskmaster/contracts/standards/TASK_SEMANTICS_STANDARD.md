# Task Semantics Standard

Normative scope: the semantic distinction between requested task/result requirements and response approach.

**TASK-01 — Task semantics.** Task semantics comprise operative requested actions, subjects, objects, scope, constraints, exclusions, priorities, conditions, ordering, quantities, dates, comparisons, criteria, audience, definitions, relationships, requested output characteristics, requested conclusions, and other operative instructions that constrain substantive work or its required result.

**TASK-02 — Approach semantics.** Approach semantics comprise instructions that change only how an already-defined task will be carried out, including research method, evidence-selection method, comparison method, scoring technique, analysis order, justification procedure, and other high-level procedural choices that do not independently alter `TASK-01`.

**TASK-03 — Pre-Plan semantic partition.** Before a Response Plan exists, semantic processing of an operative request MUST preserve any `TASK-02` semantics separately for later Plan use while `TASK-01` semantics are represented through Prompt Pseudocode.
